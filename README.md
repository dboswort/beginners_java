# Guest List Manager
A simple console-based Java application for managing a guest list. Designed as an education tool for learning core Java concepts such as arrays, loops, conditionals and basic I/O with `Scanner`.

## Features

- View current guests
- Add a guest to the first empty slot
- Remove a guest by number (and compact the list)
- Rename a guest (remove + add)
- Insert a guest at a specific position
- Pre-loaded with some test names

## Requirements

- Java 8 or later
- A terminal / command prompt

## How to run

From the project root:

```bash
javac src/Main.java
java -cp src Main
